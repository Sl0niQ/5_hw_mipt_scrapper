# 5_hw_mipt_parser
## Скраппер для сбора данных о движении Международной Космической Станции (МКС)
## Задача:
- собрать данные о текущих положении и скорости движении МКС (широта, долгота, высота, текущая скорость);
- обработать данные, построить график изменения скорости движения МКС по времени.

## Описание:
- скраппер:
    - подключается к сайту НАСА https://www.nasa.gov/spot-the-station/
    - собирает параметры МКС раз в 45 сек с сохранением в буфер
    - при заполнении буфера (размер буфера = 50 записей) сохраняет данные в файл iss_data.csv
    - запуск скраппера из консоли: python iss_data_scrapper.py  
    - для преращения работы приложения набрать в консоли exit и нажать Enter
    - файл iss_data.csv создается в той папке, откуда запускается скраппер; если файл существует, новые данные добавляются в конец файла 
- анализ данных:
    - построение графиков выполняется с использованием библиотеки matplotlib
    - для запуска набрать в консоли python iss_data_analyze.py
    - файл с "сырыми" данными должен находиться в той же папке, откуда запускается приложение
- список используемых библиотек в файле requirements.txt
